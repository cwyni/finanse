# Finanse

Prywatny licznik zarobków i wydatków w złotówkach. Jeden plik HTML, bez serwera.

Strona: https://cwyni.github.io/finanse/

Dane zapisują się tylko w przeglądarce, w której je wpisujesz. Nie trafiają do tego repozytorium ani nigdzie indziej.
Rób kopię zapasową (link na dole strony), a na innym urządzeniu użyj „Przywróć kopię”.
